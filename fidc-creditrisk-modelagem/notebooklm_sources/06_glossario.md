# Glossário

- **FIDC:** Fundo de Investimento em Direitos Creditórios. **Duplicata:** recebível comercial. **Cedente:** quem vende o recebível. **Sacado:** devedor da duplicata.
- **Deságio:** desconto na compra do recebível; é a receita de crédito do fundo. **Excesso de spread (XS):** deságio menos custo da sênior e despesas.
- **Cota sênior / subordinada:** a subordinada absorve perdas primeiro. **Subordinação:** fração do PL em cotas subordinadas.
- **PD:** probabilidade de default. **LGD:** perda dado o default (1 − recuperação, a valor presente). **EL:** perda esperada = PD × LGD × exposição.
- **VaR q:** perda que só é excedida com probabilidade 1−q. **ES q:** média das perdas além do VaR. **Perda inesperada:** diferença entre cauda e EL.
- **CreditRisk+:** modelo atuarial de perdas de crédito (CSFB, 1997), Poisson misturado com fator Gamma. **Panjer:** recursão exata para a distribuição da soma composta.
- **Cópula:** função que liga distribuições marginais à dependência. **Gaussiana:** sem dependência de cauda. **t:** com dependência de cauda (graus de liberdade ν).
- **Vasicek/ASRF:** modelo de fator único para carteira infinitamente granular. **Correlação de default:** correlação entre os indicadores de default de dois devedores.
- **HHI / número efetivo de sacados:** medidas de concentração (1/HHI = quantos sacados iguais dariam a mesma concentração).
- **Roll-rate / vintage:** métodos empíricos para estimar PD a partir de migração entre faixas de atraso ou de safras de originação.
- **CVM Informe Mensal:** declaração mensal obrigatória do FIDC; dados agregados e abertos.
